## 6-4 進階玩法：Plugin

OpenCode Plugin 文件: <https://opencode.ai/docs/zh-tw/plugins/>

OpenPets 官方網站: <https://openpets.dev/>

```sh
xattr -dr com.apple.quarantine /Applications/OpenPets.app
```

PetDex 官方網站: <https://petdex.dev/>

```sh
npx petdex@latest install (Pet名稱)
```

設計 Telegram 通知 Plugin：

Telegram 註冊教學: <https://hackmd.io/@flagmaker/S1Cp6uBlzx>

```text
請先參照 https://opencode.ai/docs/plugins/ 幫我設計一個 Plugin，當 Agent 完成任務閒置（ session.idle ）、或是需要徵求使用者同意（ permission.asked ）時，透過 Telegram Bot 發送通知給我，請使用 TypeScript 撰寫，並將 API token 與 CHAT_ID 設為變數，方便我後續修改。

1. 從 .env 檔案讀取 Bot Token 和 CHAT_ID
2. 使用 Telegram Bot API 發送推播訊息
3. 建立 .env 檔案來儲存 Telegram 設定。
```

OpenCode Plugin 官方文件: <https://opencode.ai/docs/plugins/>

安裝 Bun 與相依套件：

```sh
brew install bun
bun install
```

建立 Telegram 機器人：

Telegram BotFather: <https://t.me/BotFather>

```text
/newbot
```

Telegram Bot API 更新查詢端點: <https://api.telegram.org/bot/getUpdates>

Telegram Bot API 端點: `https://api.telegram.org/bot<TOKEN>/getUpdates`

在 .env 填入 Telegram 設定：

```text
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
TELEGRAM_CHAT_ID= 你的 ChatID
```

```text
幫我修改 .env 中的 Telegram 相關設定，我的 Bot Token 是 XXXXX，CHAT_ID 是 XXXXX。
```
